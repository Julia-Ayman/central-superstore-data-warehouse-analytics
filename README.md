# central-superstore-data-warehouse-analytics
SQL Server data warehouse and business analytics project built using the Central Superstore dataset. Includes a Staging → Bronze → Silver → Gold data pipeline, star schema with fact and dimension tables, advanced SQL queries, KPI views, stored procedures, and query performance optimization.
Includes 15 business-analysis queries and 3 interactive Tableau dashboards showing that discounts above 20% turn profit negative.
